# Optional location sharing and next source

The header picker offers **Use my location**. It requests browser permission only after a click; denial, errors, unsupported browsers, imprecise coordinates and missing coverage keep manual selection usable. Coordinates are neither transmitted nor persisted by application code. Browser-local Haversine proximity uses aggregate coordinates of imported establishments; it suggests up to three covered cities within approximately 50 miles. This is a discovery aid, not a jurisdiction boundary or complete-coverage claim. The visitor chooses a suggestion before navigation; the existing city preference is remembered.

No new database migration. `coveredCities()` adds validated aggregate coordinates; cities without coordinates remain manually accessible. Existing publication gates apply. Browser tests used an isolated temporary route rendering the real picker with synthetic city coordinates; that route was removed. Screenshots were visually checked at 1440, 1200, 768, 390 and 360. Permission grant, denial, timeout, missing API, imprecise results, no nearby coverage and manual fallback were exercised. Hosted verification is separate.

Montgomery County's `dkrp-gr48` adapter uses the shared bounded Socrata connector and remains disabled by default. Publisher metadata declares daily refresh, July 2024 onward, Public Domain. The adapter retains original records and result/checklist strings, including Corrected Onsite. Unknown checklist values reject the import. No score or severity is invented. `node backend/validate-montgomery.mjs` verifies 25 real records in disposable local PGlite: exact native parity, unchanged repeat import, name/city search, profile history and failed-import retention. See `MONTGOMERY_SOURCE_VALIDATION.json`. This does not prove hosted Neon import or full county coverage.

Command Center remains at `/admin`, absent from public navigation/footer, with owner authentication and server authorization. Search-engine exclusion is present. Owner provisioning, MFA, production release and actual scheduled delivery are still pending. No public admin link or separate application was added.
